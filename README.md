> “Prisma de Excelência” representa a união de diferentes talentos, ideias e habilidades que convergem para um único objetivo: alcançar resultados de qualidade e destaque. Assim como um projeto estrutural depende da colaboração entre planejamento, cálculos, testes e execução, nossa equipe transforma dedicação e conhecimento em soluções eficientes e inovadoras.

# Aprendizagem por Projeto Integrado (API)

A Aprendizagem por Projeto Integrado (API) é uma metodologia educacional baseada no desenvolvimento de projetos práticos e interdisciplinares, permitindo que os estudantes integrem conhecimentos de diferentes áreas para solucionar problemas reais. Neste semestre, o desafio consiste no desenvolvimento de uma **ponte de palitos**, envolvendo pesquisa, projeto estrutural, construção de protótipos, testes de resistência e análise dos resultados.

O projeto é conduzido utilizando a metodologia **Scrum**, organizando as atividades em sprints e promovendo planejamento, acompanhamento contínuo, colaboração em equipe e entregas incrementais ao longo do desenvolvimento.

# Projeto (API)

Este projeto tem como finalidade pesquisar, projetar e desenvolver uma ponte de palitos capaz de suportar a maior carga possível utilizando uma quantidade limitada de materiais. Durante o desenvolvimento serão estudados princípios de resistência dos materiais, equilíbrio, distribuição de esforços e eficiência estrutural, aplicando conceitos da Engenharia de Produção em um desafio prático.

A proposta envolve pesquisa bibliográfica, elaboração do projeto estrutural, construção de protótipos, realização de testes experimentais e análise dos resultados obtidos.

# Objetivo do Projeto

Desenvolver uma ponte de palitos otimizada, aplicando conceitos de engenharia para obter uma estrutura leve, resistente e eficiente, capaz de suportar elevadas cargas durante os testes.

### Objetivos específicos

- Realizar pesquisa sobre diferentes modelos estruturais de pontes;
- Estudar os esforços mecânicos e a distribuição de cargas;
- Elaborar o projeto estrutural da ponte;
- Construir protótipos para validação das ideias;
- Realizar testes de resistência e registrar os resultados;
- Analisar o desempenho da estrutura e propor melhorias;
- Utilizar o GitHub para organização e versionamento do projeto.
